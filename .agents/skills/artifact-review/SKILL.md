# Artifact review

Use this skill to assess whether an Artifact is ready to guide later work.

1. Restate the decision, affected boundary, and excluded work. **Done when scope can be distinguished from implementation work**
2. Check that alternatives and trade-offs are meaningful rather than labels. **Done when the recommendation has a reason**
3. Check that acceptance evidence would falsify an incomplete decision. **Done when evidence is observable and bounded**
4. List unresolved assumptions and assign them to a later Artifact or Slice. **Done when no hidden policy is treated as settled**

Use `/review-convergence` for evidence, disposition, and repair limits. Do not turn a review into implementation.
